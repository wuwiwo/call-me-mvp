# 安全说明（威胁模型）

> 本文件记录本项目的**安全事实**，重点是访问提示（密码门）的真实防护能力。
> 目的：让**代码、文案、文档三者表述一致且诚实** —— 不夸大防护能力。

## 1. 结论速览

| 问题 | 答案 |
|---|---|
| 这个访问提示能保护数据吗？ | **不能。** 它是 UI 级访问提示，不是安全边界。 |
| 有真正受保护的资产吗？ | **没有。** 默认密码、webhook URL 对任何能打开页面的人都可见。 |
| 绕过成本？ | **≈ 0**：读源码、开 DevTools、或清掉 LocalStorage 即可。 |
| 它挡得住谁？ | 只挡「完全不熟悉技术的随手访问者」，以及防止自己误触。 |
| 会删掉它或升级成"真"校验吗？ | 不删除；也不做 hash / 加密 / 混淆 / 服务端校验（见 §5）。 |

## 2. 资产

**没有真正受保护的资产。** 具体说：

- `js/modules/config.js` 里的默认密码与 webhook URL 直接写在**前端源码**中，
  任何能打开页面的人都可以通过「查看源代码」或 DevTools 读到。
- 密码（无论默认值还是用户自设）存在 **LocalStorage**：
  `accessPassword`（明文）、`passwordSetTime`（时间戳）。同源脚本或 DevTools 可读写。
- 页面部署为静态站点，所有资源都是公开可获取的。

## 3. 对手模型

**对手 = 任何能打开这个页面的人。** 不区分身份、不需要任何凭据。

对手的能力上界至少包括：

- 读取全部前端源码（含默认密码与 webhook URL）
- 用 DevTools 读写 LocalStorage、直接调用页面里的模块函数
- 清空 LocalStorage 让"有效期"立刻重置

在此前提下，任何客户端校验都可被绕过，成本与阅读源码同级。

## 4. 结论：它实际防什么

访问提示（`js/modules/password.js`）**只防两件事**：

1. **防误触** —— 避免随手打开页面的人误操作按钮。
2. **挡完全不熟悉技术的随手访问者** —— 对方不会按 F12、不会看源码。

它**不防**任何有意绕过的人。这正是本文件存在的意义：
避免把"页面上有个密码框"当成"有安全防护"。

### 4.1 有效期的真实语义

`expiryDays = 7`（`js/modules/config.js`）是**本地时间戳比较**：

- 验证通过时写入 `passwordSetTime = Date.now()`；
- 之后每次加载比较 `Date.now() - passwordSetTime` 是否超过 7 天；
- **清空 LocalStorage（或改写 `passwordSetTime`）即可立刻重置**，
  与服务端无关，也不存在任何服务端有效期概念。

> 记录损坏（非数字 / NaN / 空串）按「已过期」处理 —— 对一道闸门来说，
> 坏数据应当倾向于要求验证，而不是反过来（历史实现里 `NaN > x` 恒为 false，
> 会让损坏的时间戳变成"永不过期"）。

## 5. 为什么不做成"真"校验

**纯前端没有秘密可言。** 在当前部署形态下：

- 没有服务端可以托管秘密；
- 任何写进前端的校验逻辑、hash、混淆，都能被静态阅读并绕过；
- 引入 hash 只会制造"它更安全了"的**错误印象** ——
  在没有秘密可用时，伪装安全性比明文更有害：它让人误判风险、做出错误的信任决策。

因此本项目的立场是：**明确声明它是访问提示，不投入任何"看起来更安全"的手段。**
若将来确实需要保护资产，正确做法是**改变部署形态**
（服务端校验 + 真正的身份认证），而不是在前端加固这个提示。

## 6. 文案与实现的一致性（可被回归套件断言）

- 用户可见文案（`js/modules/translations.js` 的 `password.*`）遵守约束：
  **不得声称或暗示「保护 / 安全 / 加密 / 授权」**。
  `password.hint` 明确说明「任何能打开本页的人都能绕过它」。
- `tools/password-gate.mjs` 会断言：四语言 `hint` 均为诚实表述、
  不含上述禁用词，且四个取值互不相同。
- 密码配置的**唯一来源**是 `js/modules/config.js` 的 `CONFIG.password`；
  `js/modules/password.js` 只读取它，不再硬编码副本。
  回归套件会断言 `password.js` 内不出现默认密码字面量与硬编码过期天数。

## 7. 范围

本文件只描述**当前实现的安全事实**，不构成本仓库其他部分的安全评估。
webhook、JSONBin 回执等链路各有自己的信任假设，见
`docs/DATA_FLOW.md` 与 `docs/ARCHITECTURE.md`。
