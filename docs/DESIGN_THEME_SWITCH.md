## 5. 硬约束（写代码前必读）

### 5.1 DOM 契约已被测试钉死 ★

主题只能通过 CSS（order / grid / flex / 显隐 / 尺寸）改排布，**不能删改这些结构与 id**。
本次 grep 实测（`tools/*.mjs`，三个选择器合并命中 **20 处**）：

| 文件 | 命中数 |
|---|---|
| `input-safety.mjs` | 9 |
| `cooldown.mjs` | 3 |
| `button-ids.mjs` | 3 |
| `storage-resilience.mjs` | 2 |
| `receipt-lifecycle.mjs` | 2 |
| `e2e.mjs` | 1 |
| `history-language.mjs:732` | 1（`document.getElementById('languageToggle')`，非选择器形式） |

推论：
- `#editButtons` 即使移进 ⋯ 菜单，**节点必须留在 DOM**（隐藏元素仍可被 `.click()`，测试如此驱动）。
- `.bubble-container .bubble-btn`、`.bubble-btn .bubble-content i / span` 的内部结构不可改。
- `history.html` 复用 `.top-bar`，顶栏重构要同步改。
- 若某主题需要**新的 DOM 节点**（例如底部 Tab），必须在 `index.html` 预埋 + 主题控制显隐，不能运行时创建。

### 5.2 其他约束

- **不做深色模式**：所有主题浅色，对比度问题仍需满足（见 5.3）。
- **FOUC**：ES module 是 defer，主题必须在 `<head>` 内联脚本写入 `data-theme` 后再渲染。
- **history.html 只加载 `history.js`**：主题 init 要在该页补一次（照 CM-007 `language.init()` 先例）。
- **4 语言文案**：zh / en / ja / ko 都要齐，新增键四语言齐全且取值互不相同（项目既定纪律）。
- **480 / 360 断点**：顶栏控件数量变化后必须同步复核。
- `zh.history.webhookLabel` 必须保持 `Webhook`（被 `tools/input-safety.mjs:1024` 钉死）。

### 5.3 已知风险

| 风险 | 说明 |
|---|---|
| 硬编码色 | `index.css` `:root` 之外 **61 行**；`history.css` **21 行**且零本地令牌（用 `#eee/#666/#f8f9fa/#ff6b81/#ff4757`，与首页不同源）；JS 内联样式 1 处（`password.js:172`） |
| 玻璃令牌是浅色专用 | `--glass-bg/border/shadow-inset` 全部由「白」构成，深色主题需整组重定义（本需求暂不涉及，但令牌化时要把这层单独抽象） |
| 背景与标题写死 | `index.css:57-58` 双 radial 光晕、`:171` 标题渐变（带 `titleShine` 6s 动画）——必须参数化，否则主题切换后背景仍是旧光晕 |
| **标题对比度不足** | 薄荷渐变 H 在 `#F7F6F3` 上：暗端约 **2.9:1**、亮端约 **1.6:1**，低于 WCAG 大字号 3:1 下限。**尚未处理**，两个备选：① 同色相加深 `#0A7D5F→#0E9673`（≥3.3:1）；② 深玻璃带 `#0E3B30` + 亮薄荷字（约 7:1） |
| 历史入口提案 | 06 屏底部「查看通知历史」是设计提案，非现状功能，需确认是否纳入 S3 |
